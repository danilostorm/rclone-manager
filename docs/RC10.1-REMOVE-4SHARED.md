# RC10.1 — retirada do 4shared

## Motivo

Nos testes reais do RC10, o endpoint oficial `https://api.4shared.com/v1_2/oauth/authorize` aceita o Request Token e abre a tela de login. A conta chega a autenticar no 4shared, porém a etapa de autorização/consentimento não conclui de forma confiável e o navegador não retorna ao callback do Rclone Manager.

Como o projeto não quer depender de JDownloader, scraping de login, cookies de navegador ou automação de CAPTCHA, o suporte ao 4shared foi retirado.

## Mudanças

- remove o card 4shared de Configurações → Integrações;
- mantém todas as abas de Configurações introduzidas no RC10;
- remove as rotas OAuth 4shared;
- remove `app/oauth_4shared.py`;
- limpa Consumer Key/Secret, Request/Access Tokens e metadados de conta 4shared previamente armazenados no SQLite;
- novos links 4shared são recusados com mensagem explícita;
- jobs antigos 4shared não são executados;
- API da extensão passa para `drive-link-v12`;
- extensão 1.5.1 não captura mais `4shared.com` nem `4s.io`.

## Segurança

Nenhum fallback por senha, cookie, CAPTCHA, scraping ou JDownloader foi implementado.
